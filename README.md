# SwiftResume

模块化、离线优先的中文简历浏览器扩展。简历内容以结构化 JSON 保存，编辑界面与排版模板彼此独立。

## 当前能力

- 固定个人信息、结构化教育经历和通用内容三类简历组件
- 通用内容统一使用“可选主标题、副标题、时间 + 富文本正文”
- 标题行全部留空时仅显示正文，可用于专业技能、自我评价和个人优势
- 富文本正文使用 Tiptap 官方扩展，支持段落层级、字号、字体、字重、颜色、高亮、行高、缩进、对齐、引用、列表、链接、分隔线和表格，并与预览、PDF 共用内容语义
- 模块增删、复制、隐藏、拖动排序和按钮上下移动
- 多份简历的新建、切换、复制和独立保存
- A4 实时预览、连续排版密度和自定义强调色
- 预览、打印和 PDF 支持经典线框、极简留白、商务蓝顶、现代侧栏、垂直强调、经历时间轴、学术素雅、技术简洁和紧凑分栏九套模板
- 整页编辑画布固定使用经典模板，切换输出模板不会改变编辑布局或简历内容
- 预览面板可随时收起或重新展开，收起后自动扩大编辑区域
- IndexedDB 自动保存，JSON 导入和手动备份
- 用户授权目录的自动磁盘镜像、定时历史快照和整库恢复
- 多个浏览器页面实时同步，默认开启并可随时关闭
- 设置页可调整同步/保存延迟、导出方式、溢出提示和预览缩放
- 浏览器内 Typst/WASM 中文 PDF 导出，失败时自动使用打印方案

## 本地开发

```bash
npm install
npm run dev
```

## 加载扩展

```bash
npm run build
```

然后在 Chrome 或 Edge 的扩展管理页面启用开发者模式，选择“加载已解压的扩展”，加载 `dist` 目录。

Typst、WASM 和中文字体都会打包进 `dist`，运行和导出时不依赖远程服务。

内置中文字体为 Noto Sans CJK SC，采用 SIL Open Font License 1.1；许可证保存在 `public/fonts/LICENSE-NOTO-SANS-CJK.txt`。

## 本地磁盘备份

在设置的“本地磁盘备份”中选择一个可写目录后，扩展会在每次停止编辑约 1.5 秒后更新当前简历的磁盘镜像，并至多每十分钟为发生变化的简历保留一个历史快照。首次配置会立即备份全部简历。

备份目录包含 `index.swiftresume.json`、`resumes/`、`assets/` 和 `history/`。`resumes/` 始终保存每份简历的最新版本；`assets/` 保存从简历 JSON 中额外提取的独立证件照；`history/` 保存用于回退的定时版本快照，每份简历最多保留最新 20 份。JSON 本身仍包含 Base64 图片数据，因此单独复制一个简历 JSON 也可以完整恢复图片。

浏览器重启或目录权限被系统收回后，设置页会提示重新授权；权限失效不会影响 IndexedDB 中的正常自动保存。“立即备份”只刷新最新版本，不会为未变化的内容重复创建历史快照。

启动时会自动复用此前保存的目录授权；权限仍有效时不会打扰用户。未配置目录或权限失效时，工作台会显示数据安全提醒，可直接选择目录或重新授权原目录。

设置页的“历史版本”可以按简历查看快照并进行 A4 预览，也可以手动创建快照、恢复为新简历或在确认后覆盖原简历。
