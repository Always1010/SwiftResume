# SwiftResume

SwiftResume 是一款模块化、离线优先的中文简历浏览器扩展。简历数据以结构化 JSON 保存，内容编辑与排版模板相互独立：只需维护一份内容，即可随时切换模板并导出 PDF。

## 核心特性

- **模块化编辑**：支持个人信息、教育经历和通用内容三类组件；模块可以新增、复制、隐藏和排序。
- **灵活的内容结构**：通用内容由可选的主标题、副标题、时间和富文本正文组成，可用于项目经历、工作经历、专业技能、自我评价等场景。
- **丰富的正文格式**：支持字体、字号、字重、颜色、高亮、行高、缩进、对齐、引用、列表、链接、分隔线和表格。
- **多份简历管理**：可以新建、切换和复制简历，各份简历独立保存。
- **实时 A4 预览**：支持排版密度、强调色和预览缩放调节，并在内容溢出时给出提示。
- **29 套输出模板**：覆盖经典商务、编辑排版、网格主义、技术档案和创意作品集等风格；切换模板不会改变简历内容或编辑布局。
- **本地数据保护**：使用 IndexedDB 自动保存，支持 JSON 导入、手动备份、磁盘镜像和历史版本恢复。
- **多页面同步**：同一浏览器中打开的多个 SwiftResume 页面可以实时同步，也可以在设置中关闭。
- **离线 PDF 导出**：内置 Typst/WASM 和中文字体，可直接生成矢量 PDF；导出失败时自动切换到浏览器打印。

## 安装与使用

目前需要从源码构建并加载扩展。请先安装 Node.js 和 npm，然后运行：

```bash
npm install
npm run build
```

构建完成后，在浏览器中加载 `dist` 目录：

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展”，选择本项目生成的 `dist` 目录。
4. 点击浏览器工具栏中的 SwiftResume 图标开始使用。

代码更新后，重新运行 `npm run build`，再到扩展管理页面点击“重新加载”即可。

## 基本流程

1. 新建简历，或复制现有简历作为新的求职版本。
2. 添加所需模块并填写内容，通过拖动或按钮调整顺序。
3. 在 A4 预览中检查分页和内容溢出，按需调整模板、密度与强调色。
4. 导出 PDF；需要迁移或手动留档时，可同时备份 JSON。

## 数据保存与备份

简历默认自动保存在浏览器的 IndexedDB 中，所有内容均留在本机。工具栏中的“备份 JSON”可导出当前简历，之后可通过导入功能完整恢复；JSON 中包含 Base64 图片数据，因此单个文件即可保留证件照。

如需额外保护，可在设置中授权一个本地目录。SwiftResume 会在停止编辑约 1.5 秒后更新当前简历的磁盘镜像，并至多每 10 分钟为有变化的简历创建一次历史快照。每份简历最多保留最近 20 个快照。

备份目录结构如下：

| 路径 | 内容 |
| --- | --- |
| `index.swiftresume.json` | 备份索引 |
| `resumes/` | 每份简历的最新版本 |
| `assets/` | 从简历中提取的独立图片 |
| `history/` | 可预览和恢复的历史快照 |

首次选择目录后会立即备份全部简历。若浏览器重启或系统收回目录权限，只需按提示重新授权；这不会影响 IndexedDB 中的自动保存。历史版本可以恢复为新简历，也可以在确认后覆盖原简历。

## 隐私与离线能力

SwiftResume 不会将简历上传到服务器。Typst、WASM 与 Noto Sans CJK SC 中文字体均打包在扩展中，编辑、保存和 PDF 导出无需远程服务。
