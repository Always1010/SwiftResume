# SwiftResume 问题日志

## SR-016：收起预览时浏览器打印缺少简历内容

- 日期：2026-09-17
- 状态：已解决
- 现象或修改背景：专注编辑或关闭预览后，浏览器打印缺少简历页面。
- 原因分析：页面预览被条件卸载，而打印样式又隐藏编辑画布，打印时没有剩余的简历内容节点。
- 解决方案：在预览关闭时保留仅用于打印的离屏分页内容；PDF 导出新增真实文件预览，并让生成失败后的打印入口由用户主动选择。
- 验证方式：导出对话框测试覆盖同一文件预览和下载、错误重试及关闭后的资源释放；检查专注编辑模式仍有完整分页节点，并执行正式构建。
- 相关文件：`src/App.tsx`、`src/components/PdfExportDialog.tsx`、`src/components/PdfExportDialog.test.tsx`、`src/components/StandalonePreview.tsx`、`src/export/typstPdf.ts`、`src/workspace.css`

## SR-015：窄窗口中编辑表单受挤压并产生横向溢出

- 日期：2026-09-17
- 状态：已解决
- 现象或修改背景：三栏最小宽度大于常用窗口宽度，正文编辑区过窄；内容条目的三列表单在窄编辑区被截断。
- 原因分析：工作区采用固定列宽，表单仅按窗口宽度响应，预览默认按原始 A4 宽度显示。
- 解决方案：增加专注编辑、可折叠目录及窄窗口编辑/预览切换；表单按容器宽度排列，预览支持自动适应宽度，次要文件操作收进菜单。
- 验证方式：类型检查、现有预览和设置测试；浏览器检查宽窄窗口的编辑、预览及横向溢出。
- 相关文件：`src/App.tsx`、`src/workspace.css`、`src/components/ResumePreview.tsx`、`src/settings/appSettings.ts`、`src/components/SettingsPanel.tsx`、`src/main.tsx`

## SR-001：预览关闭入口在窄窗口中不可见

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：实时预览原本只在预览工具栏最右侧提供关闭按钮；工作台横向空间不足时，该按钮可能处于当前可视区域之外，用户无法发现或操作预览关闭功能。
- 原因分析：关闭入口依赖预览面板自身的完整可见性，没有在始终可操作的全局工具栏提供等价控制。
- 解决方案：在顶部工具栏增加带开启状态的“关闭预览 / 开启预览”切换按钮；保留预览面板原关闭按钮和关闭后的侧边恢复入口。
- 验证方式：执行完整单元测试和正式构建，并确认开关使用 `aria-pressed` 暴露当前状态。
- 相关文件：`src/App.tsx`、`src/styles.css`

## SR-002：未变化的简历可能产生重复历史快照

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：重复点击立即备份、重新授权目录或进行全量备份时，即使简历内容没有变化，也可能在 `history` 中产生新的 JSON 文件。
- 原因分析：历史快照只记录了上次生成时间，强制备份路径没有比较简历的 `updatedAt`，并且立即备份默认总是要求创建快照。
- 解决方案：历史状态同时记录快照时间和简历版本；自动快照仅在内容变化且距上次至少十分钟时创建，立即备份只刷新 `resumes` 最新版本，首次选择新目录仍创建初始快照。
- 验证方式：补充首次快照、未变化跳过、十分钟节流和图片提取测试，并执行正式构建。
- 相关文件：`src/App.tsx`、`src/storage/diskBackup.ts`、`src/storage/diskBackup.test.ts`

## SR-003：历史快照缺少应用内查看和恢复入口

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：磁盘备份会生成 `history` 快照，但用户只能在文件系统中看到 JSON，无法在 SwiftResume 内确认快照内容或恢复指定版本。

- 解决方案：增加历史版本管理页面，支持按简历列出快照、A4 完整预览、手动创建、删除、恢复为新简历以及覆盖原简历；覆盖前先保存当前内容的历史快照。
- 验证方式：执行完整单元测试和正式构建，检查历史读取和恢复操作的类型与界面状态。
- 相关文件：`src/App.tsx`、`src/components/HistoryPanel.tsx`、`src/components/SettingsPanel.tsx`、`src/storage/diskBackup.ts`、`src/styles.css`

## SR-004：磁盘目录未配置或权限失效时缺少启动提醒

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：用户未选择备份目录或浏览器收回目录权限后，打开工作台只显示顶部状态文字，容易在没有磁盘保护的情况下继续编辑。
- 原因分析：启动流程虽然会恢复已保存的目录句柄并查询权限，但没有对未配置、待授权和读取失败状态提供必须处理的醒目提示。
- 解决方案：启动时复用 IndexedDB 中持久保存的目录句柄并查询读写权限；权限有效时静默继续，未配置或待授权时显示不可点背景关闭的提醒弹窗，提供选择目录、重新授权原目录和本次稍后处理。
- 验证方式：执行完整单元测试和正式构建，检查不同备份状态对应的弹窗文案和按钮路径。
- 相关文件：`src/App.tsx`、`src/components/BackupSetupPrompt.tsx`、`src/styles.css`

## SR-005：组件搭建排序低效且字段排版能力缺失

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：组件和模块只能通过逐次点击上移、下移调整位置；标题、说明、列表以及键值字段无法分别设置字号、字重、字体和颜色。

- 解决方案：模块列表保留直接拖放，组件列表改用带键盘支持的拖拽排序并删除上下移动按钮；为每个语义字段增加独立文字样式，并同步到实时预览和 Typst 导出。
- 验证方式：执行类型检查、完整单元测试和正式构建；测试组件样式会生成对应 Typst 字号、字重及颜色参数。

## SR-006：自由文档与组件搭建仅是同一内容的视图切换

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：自由文档复用了组件搭建的数据和输入框，操作方式与组件搭建没有本质区别；内容块的操作栏持续占位，缺少自然输入、斜杠菜单和块级拖动体验。

- 解决方案：自由文档改用 BlockNote，提供段落、标题、列表、勾选项、引用、代码、表格、简历快捷块、斜杠菜单和悬停侧边菜单；单独保存块 JSON，并为旧自由文档自动迁移原节点和隐藏状态。
- 验证方式：执行类型检查、完整单元测试和正式构建；补充三种模式数据隔离、旧自由文档迁移、隐藏块不导出的测试。

## SR-007：富文本编辑器能力有限且格式无法稳定进入导出

- 状态：已解决

- 验证方式：执行类型检查、完整单元测试和正式构建；补充富文本样式白名单、危险标记清理、表格和安全链接保留以及 Typst 格式转换测试。

## SR-008：切换内容数量不同的简历时预览可能崩溃

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：预览已经分页后切换到内容项目更少的简历，页面可能变为空白并抛出读取未定义项目属性的异常。
- 原因分析：简历切换后的第一次渲染仍短暂沿用上一份简历的分页索引，其中部分索引超出新简历的内容项目范围。
- 解决方案：渲染分页项目时忽略已失效索引，随后由布局测量正常生成新简历分页。
- 验证方式：正式构建后在浏览器切换内容数量不同的简历，页面保持可用且控制台无新增异常。
- 相关文件：`src/components/ResumePreview.tsx`

## SR-010：简历编辑依赖单模块页面切换

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：编辑区一次只显示一个模块的表单，修改不同模块时需要在侧栏反复切换，无法结合整份简历的上下文确认内容和顺序。
- 原因分析：编辑器和实时预览是两个完全分离的渲染路径，模块选中状态直接决定唯一显示的表单，没有连续文档画布和展示、编辑状态的切换机制。
- 解决方案：将中间区域重构为不分页的连续简历画布；侧栏点击仅滚动定位且不关闭编辑，点击画布中的个人信息或模块后原位切换为编辑表单，同时只允许一个区域编辑；切换模块、点击完成或点击简历纸张外围的灰色背景时提交当前内容，纸张内部留白和其他界面区域不改变编辑状态。
- 验证方式：执行完整单元测试和正式构建，并在浏览器中验证连续展示、侧栏定位、单模块原位编辑、模块切换保存及灰色外围点击退出行为。
- 相关文件：`src/App.tsx`、`src/components/EditorPanel.tsx`、`src/components/ResumeEditorCanvas.tsx`、`src/components/ResumePreview.tsx`、`src/styles.css`

## SR-012：隐藏模块仍出现在整页编辑画布

- 日期：2026-09-15
- 状态：已解决
- 现象或修改背景：从侧栏隐藏模块后，右侧分页预览会隐藏该模块，但中间的整页简历画布仍以半透明样式展示它，导致两个简历展示结果不一致。
- 原因分析：整页画布遍历了全部模块，仅用样式标记隐藏状态，没有按 `enabled` 状态过滤。
- 解决方案：整页画布只渲染已启用模块；隐藏操作仍保留在侧栏，若正在编辑的模块被隐藏，则保存内容并结束该模块的编辑状态。
- 验证方式：补充整页画布隐藏模块回归测试，并执行完整单元测试和正式构建。

## SR-013：侧栏切换模块不会切换就地编辑器

- 日期：2026-09-16
- 状态：已解决
- 现象或修改背景：正在画布中编辑一个模块时，点击侧栏中的另一个模块只会改变定位状态，原模块仍保持编辑，用户还需要再次点击画布才能切换。
- 原因分析：侧栏选择状态由应用层管理，就地编辑状态则封装在画布组件内部，两者无法协调保存、关闭和打开顺序。
- 解决方案：将就地编辑状态提升到应用层统一管理；侧栏选择可见模块时先保存当前编辑内容，再关闭旧模块、打开目标模块并滚动定位，同时保证任意时刻只有一个编辑器打开。
- 验证方式：补充受控编辑状态回归测试，并执行完整单元测试和正式构建。
- 相关文件：`src/App.tsx`、`src/components/ResumeEditorCanvas.tsx`、`src/components/ResumeEditorCanvas.test.tsx`

## SR-013：经历首行与自由正文被割裂为互斥编辑模式

- 日期：2026-09-16
- 状态：已解决
- 现象或修改背景：项目模块能稳定显示名称、职责和日期，但正文标签及结构写死；组件搭建无法在同一段内自由加粗；自由文档和富文本又无法稳定表达右对齐日期。用户必须在三种各有缺口的模式中选择，仍不能自然完成常见简历条目。
- 原因分析：数据模型按编辑器技术形态拆分，而不是按简历内容语义建模；标题日期行和自由正文分别归属不同模型，并在编辑、预览及 PDF 中维护了多条渲染路径。
- 解决方案：升级为不兼容的 schema v2，删除三模式及 BlockNote 实现；项目、工作和自定义模块统一为可重复的内容条目，每条由可选标题、补充信息、日期和 Tiptap JSON 正文组成。首行全部留空时只渲染正文，预览与 Typst 直接消费同一数据语义。
- 验证方式：补充模型、预览和 Typst 测试，执行完整单元测试与正式构建，并在浏览器验证标题日期对齐、纯正文模块、局部加粗及列表编辑。
