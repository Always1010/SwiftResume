# HTML/CSS 与 Typst 统一输出

日期：2026-09-18

默认使用 HTML/CSS；在设置的“预览与 PDF 输出方式”中可切换为 Typst。
两种方式共用编辑区右侧预览、模板预览、导出前检查与导出入口。Typst 依赖、模板与直接下载能力均保留。

## 使用

重新加载构建后的扩展，在 **设置 → 保存与导出 → 预览与 PDF 输出方式** 中选择 HTML/CSS 或 Typst。设置自动保存，并同步到已经打开的模板预览。
两种预览均保留缩放、适应宽度、页数、密度、配色、头像底色；HTML 页面固定 A4 宽度，缩放不会改变换行。
从工作台或模板预览点击 **打印 / 保存 PDF**，在同一个窗口检查排版后点击底部的打印按钮。原生打印窗口直接在当前标签页打开，选择另存为 PDF，纸张 A4、缩放 100%、边距无、关闭页眉页脚、开启背景图形。

最终保存由浏览器控制，应用不能确认文件是否落盘，也不再维护岗位版本或导出记录。取消打印后保留导出确认窗口；返回后编辑器、内容与操作历史保持原状。打印从已排好的 DOM 克隆出只用于打印的页面，结束或失败后移除，不导航、不卸载编辑器。旧版打印链接仅保留读取和返回编辑入口，新的导出流程不再创建独立快照任务。

## 实现

- 复用 `ResumeProfileView`、`ResumeSectionView` 和现有正文 CSS，保留 HTML 列表标记、字重、行距、富文本字体及对齐方式。
- 页面固定为 210 × 297 mm，内边距沿用桌面编辑区的 28 px。编辑区本身仍随工作区宽度变化，因此编辑区与 A4 内容宽度不同时，换行位置可能不同。
- 等待字体与照片加载后，根据真实 DOM 尺寸分页。优先让短条目整体移动；当整条移动会留下超过 140 px 空白时，按段落或列表项跨页；长条目按段落、列表项或表格行拆分，超长段落按字符簇断开。模块标题与后文一起移动。
- 分页时保留富文本祖先节点、列表编号和续页样式。屏幕预览与打印直接使用同一组页面 DOM；不截图拼接、不通过另一套排版语言重建正文。
- 调节密度时直接更新已有页面的 CSS，不清空预览或反复显示加载提示；同一帧内的变化合并，只为最新值重新分页。测量在隐藏容器完成，再一次性更新可见页面，复用页壳和未变化的正文，保留滚动位置（页数减少时按浏览器可滚动范围限制）。字体准备状态和同一照片的加载请求复用；导出入口等待最新分页完成。
- 打印样式只处理页面几何、缩放和控件隐藏。打印按钮仅在最终分页就绪后可用；工作台快捷键进入导出确认窗口。
- 浏览器专用字体由原始 Noto 字体生成，字形与度量不变，排除会导致 PDF 中文反向映射错误的部首别名。字体来源、修改与许可见 `public/fonts/README.md`。

## 验证

运行 `npm run test:html-print`，使用本机 Edge 或 Chrome 生成真实 PDF。
浏览器路径可以通过 `CHROME_PATH` 指定；测试结果位于 `.vite/html-print-check/`。

| 场景 | HTML / PDF 页数 |
| --- | --- |
| 短简历（字体、圆点、教育行、个人信息） | 1 / 1 |
| 16 个项目条目 | 4 / 4 |
| 单个长项目 | 2 / 2 |
| 超长中文段落 | 2 / 2 |
| 65 行表格 | 3 / 3 |
| 70% 显示缩放 | 1 / 1 |
| 两项目页底留白 | 2 / 2 |
| 单页连续调节密度（90 次更新后的最终值） | 1 / 1 |
| 多页连续调节密度（90 次更新后的最终值） | 2 / 2 |

自动检查逐页文字完整性、A4 尺寸、内容边界、分页、字号/字重/列表样式和联系方式对齐。
PDF.js 从打印文件中提取文字，并与每页 HTML 比对；Poppler 渲染 PDF 供视觉复核。
密度回归另检查同帧更新合并、拖动时页面不被清空、页壳与未改变正文节点复用、最终字号对应最新值、字体不重复加载。可通过 `node scripts/verify-html-print.mjs density density-multipage` 单独运行连续更新场景。
历史试验曾验证跨窗口快照流程。当前单标签实现的检查与边界详见 `SINGLE_TAB_RETEST_2026-10-03.md`，不沿用旧流程的验证结论。

## 当前边界

- 浏览器打印设置会影响最终结果；网页不能强制用户的纸张、缩放、背景图形或页眉页脚选项。
- 超过一页高度的个人信息、教育条目或单个表格行会阻止导出并提示拆分，不静默裁掉内容。
- 尚未全面验证合并单元格跨页、极端富文本结构或所有系统字体；系统字体取决于本机安装情况。
- 预览是 HTML，最终 PDF 在浏览器打印窗口生成；尚未提供自动下载 PDF 字节或生成后的 PDF 内嵌预览。
- 保留两条路径及浏览器字体会暂时增加约 28 MB 构建体积。待视觉效果验收后，再评估字体资源整合和 Typst 去留。

本轮以字体、圆点、行距、段距和普通多页内容为验收重点，不承诺不同 PDF 阅读器的文字抗锯齿逐像素一致。
