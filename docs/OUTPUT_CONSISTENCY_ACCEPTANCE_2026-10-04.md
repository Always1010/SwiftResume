# 2026-10-04 编辑、预览与打印一致性验收

## 验收口径

编辑表单不要求与纸面长得一样，但必须操作同一份文档、同一版内容。成品预览、模板主预览、打印预览和最终文件，应在同一输出引擎内使用相同模板、字号/颜色/密度、内容顺序和分页。HTML 与 Typst 是两个排版引擎，不宣称二者逐像素相同。

## 已通过的自动矩阵

固定使用两份不同的虚构文档：ID `A` / `Synthetic A` / `Alice QA` 与 ID `B` / `Synthetic B` / `Bob QA`。A 曾打开模板预览后，回到编辑、修改 A，再切换 B 并在自动保存延迟内修改 B。B 的验收版本为 `Bob immediate revision`，正文依次为工作经历和项目经历，专业技能模块被隐藏；模板 `minimal`、强调色 `#2573b9`、密度 `38`。

| 路径 | 文档与版本 | 样式/内容验证 | 证据层级 |
| --- | --- | --- | --- |
| 编辑输入 | B 最新姓名与独立正文 | 即时字段值；A 内容单独保存且未被覆盖 | 真实 React 输入/状态 + 模拟存储 |
| 编辑侧成品预览 | B 最新版 | 与导出预览的完整分页 DOM `isEqualNode` 相同 | 真实 HTML 内容/分页算法，模拟几何 |
| 模板与预览主画面 | B 最新版 | 同上；模板、颜色、密度、正文顺序及隐藏标志相同 | 真实组件与分页 DOM |
| HTML 导出预览 | B 最新版 | 同模板主预览；只有工作、项目两个可见模块 | 真实导出组件与分页 DOM |
| HTML 交给打印的快照 | B 最新版，打印标题 Synthetic B | 与导出预览完整分页 DOM 相同；无 Alice 内容、无额外应用界面；退出后清理 | 真实 `printHtmlInPlace`，模拟 `window.print` |
| Typst 缓存/导出通路 | A/B 隔离，B 更新重新生成 | 同版本的成品预览、模板和导出请求复用同一 Blob；换文档/内容/模板时不复用旧 Blob | 真实缓存及既有导出组件测试，模拟编译结果 |

其他自动覆盖：旧 `resumeId=B` 地址、A 副本、新建文档、即时输入/模板/返回保留编辑器和撤销、取消待处理分页、照片延迟完成后隐藏旧预览不提交旧结果。原有 Typst 导出组件测试确认预览 Blob、下载 URL、打印 iframe 使用同一文件引用；原有源生成测试覆盖正文、模板及格式转换。

本轮补强后完整 52 文件/233 测试、TypeScript、生产构建、差异检查通过。测试并未产生可用于视觉验收的最终 PDF；模拟编译的 Blob 只验证文件身份，不能证明字体、裁切或实际打印结果正确。
