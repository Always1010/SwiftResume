# 2026-10-04 模板预览内容同步修复

## 复现与原因

用户截图对应新版编辑器的“模板与预览”入口。该入口在同一个 App 中切换显示，编辑器和预览直接接收同一个 `resume`，没有从静态模板示例替换用户内容。模板卡片小图是预制示例，主预览和对比使用当前简历，二者不是本次问题的同一条渲染路径。

确认的问题在 HTML 分页快照：两个视图保持挂载，但隐藏预览更新时仍测量 DOM。隐藏元素宽高为零，使真实分页算法无法填入内容，并保留上次成功的页。再次显示没有改变 `resume` 引用，因此不会重新分页。

修复前新增的三条集成测试均失败，断言读到的分别为旧 `Alice QA`、切换 B 后仍为 `Alice QA`、旧地址进入后修改仍为 `Bob QA`。测试只模拟浏览器几何/存储和外部能力；App、编辑字段、模板主预览、HTML 分页与页提交代码都是真实实现。这证明了代码路径的故障，不等同于已在真实浏览器完整复演用户操作。

## 修复

- 页面可见性作为分页输入，隐藏时取消待处理任务并停止测量
- 再次显示时使用最新文档重新分页；编辑器侧成品预览和模板对比遵循相同规则
- 不卸载编辑器或模板画廊，不清理浏览器数据，不替换或迁移用户简历
- 不修改模板、输出排版样式、存储结构、扩展权限或默认同步设置

## 自动回归

六项新增集成检查：

1. 预览 A → 返回编辑即时修改 → 再打开，显示新 A；保留同一输入节点和撤销能力；模板改变后编辑侧预览同步
2. 已访问 A 预览 → 修改 A → 切换 B → 在保存延迟内修改 B → 预览、模板应用和导出入参均为 B；A 独立保存，未被 B 覆盖
3. 从 `?view=preview&resumeId=B` 旧入口打开 B，再编辑后打开预览仍为最新 B，不改 A
4. 创建 A 副本并修改，显示副本内容，原 A/B 均不变
5. 已访问预览后新建并修改，显示新文档内容，原 A/B 均不变
6. 首次分页尚未执行就离开，修改后再进入，只提交最新内容，未留下隐藏测量错误

完整 52 个测试文件、231 项测试通过；TypeScript 和生产构建通过；`git diff --check` 通过。仓库无单独 lint 命令。Vite 仍提示大于 500 kB 的包体积。

原有同页路由、光标/滚动、草稿恢复、模板对比和 Typst 异步结果淘汰测试也继续通过。新测试验证导出收到哪一份文档，未新增真实打印或 PDF 文件验收。多标签消息仍按 resumeId 分频道；本次未改变或声称完整验证浏览器多标签并发写入行为。

## 真实桌面边界

已只读观察原有桌面 Edge 窗口和用户截图，确认新界面与当前入口。此前被拒绝的列表、模板返回及刷新操作没有重新尝试，也没有改用新浏览器、脚本路由或其他路径绕过。当前自动回归不代表真实交互完整验收。

待最终合并构建安装后，由用户在原页面刷新并进行同一入口复核：先预览 A，返回修改或切换 B，再进入预览，确认标题、姓名、正文一致。仍需用户操作完成实际浏览器结果确认。
